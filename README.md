# Nidaan — Windows PC का हिंदी डॉक्टर

**Nidaan** आपके Windows PC की जाँच करता है, समझाता है, और बिना डराए ठीक करता है — हिंदी में.
घर पर इस्तेमाल के लिए **free**. यह repo सिर्फ़ installers और अपने-आप updates के लिए है (source code private है).

## Download
👉 **[Releases](https://github.com/i-smiling-buddha/nidaan-releases/releases)** में सबसे ऊपर वाला `Nidaan-Setup-<version>.exe`

1. Download करके चलाएँ.
2. Beta पर अभी digital signature नहीं है, इसलिए Windows नीली window दिखा सकता है: **"Windows protected your PC"** → **More info → Run anyway**.
3. Install के लिए admin नहीं चाहिए. आगे के versions **अपने-आप** आते हैं.

## Nidaan क्या करता है
- सेहत score, RAM / CPU / disk, blue screen और crash की असली वजह
- जगह बनाएँ: सुरक्षित cache सफ़ाई, बड़े apps और data को D: पर ले जाना (app चलता रहे)
- Duplicates, एक जैसी photos, पूरा uninstaller (बचा हुआ भी)
- Backup (versions + SHA-256 जाँच), नियमित देखभाल, Defender + "दूसरी राय"
- **Vaidya** — हिंदी में पूछें, AI आपके PC पर ही चल सकता है

## वादा
- कुछ भी सीधे delete नहीं — हटाई चीज़ें **Suraksha Kaksh** में, वहाँ से वापस.
- हर बदलाव आपके बटन दबाने पर. कोई account, कोई telemetry, कोई डराने वाले alerts नहीं.
